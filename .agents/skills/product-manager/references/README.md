# Templates e Guias de Referência para Gestão de Produtos

Este diretório contém os modelos padronizados, templates práticos e estruturas de trabalho utilizados pela skill `Product Manager`.

Ao manter estes artefatos como arquivos de referência dedicados, a instrução principal da skill (`SKILL.md`) permanece focada no fluxo metodológico e governança de decisões (modelo GCCD), consumindo o conteúdo detalhado sob demanda via *progressive disclosure*.

---

## Índice de Referências

1. **[Product Requirements Document (PRD)](./prd-template.md)**  
   Template estruturado para especificação de requisitos funcionais e não-funcionais, personas, critérios de aceite BDD/Gherkin, trade-offs e métricas de sucesso.

2. **[Opportunity Assessment](./opportunity-assessment-template.md)**  
   Artefato de validação prévia de hipóteses, urgency assessment ("Why Now?"), evidências de usuários, análise de alternativas e priorização com RICE.

3. **[Go-to-Market (GTM) Plan](./gtm-plan-template.md)**  
   Guia operacional de prontidão de lançamento entre produto, engenharia, marketing, vendas e atendimento/suporte ao cliente, incluindo gates de rollout e plano de contingência.

4. **[Product Roadmap & Delivery Tracking](./roadmap-and-delivery-template.md)**  
   Templates para visão estratégica em horizontes temporais (*Now / Next / Later*), comunicação de não-escopo (*What We Are Not Building*) e acompanhamento de cadência de entregas (*Cycle Health*).
